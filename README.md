# Taller Práctico - Sistema de Citas Médicas

## 📌 Descripción del Proyecto
Este proyecto corresponde al desarrollo del taller práctico de algoritmos de búsqueda de la asignatura **Estructuras de Datos** (Universidad de Cartagena). El programa gestiona un arreglo de objetos `Cita` (código, paciente, hora y estado) e implementa manualmente:
- Búsqueda lineal ($O(n)$).
- Búsqueda binaria ($O(\log n)$) tras ordenar los elementos.
- Métodos de filtrado por paciente y comparación de rendimiento u operaciones.
